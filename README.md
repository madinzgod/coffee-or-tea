One letter answers the oldest argument in the kitchen: this program writes exactly one character, "A" — A for coffee — to the output file, and nothing else. No word, no explanation, no punctuation: the letter stands on its own as the whole answer.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
